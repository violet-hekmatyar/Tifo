# VR9-M1 用户关系补数清单

范围：仅为既有 DEMO 用户 `10002` 与既有 DEMO 用户 `11000000000000001`～`11000000000000016` 补充 20 条 USER 关注关系。目标关系行 ID 为 `18100000000090001`～`18100000000090020`，全部以 `VR9-M1-relation-*` 标记归属。

## 关系覆盖

- `10002 → 11000000000000001..10`：本人关注 10 条，其中 01、02 有反向关系，形成 `MUTUAL`。
- `11000000000000009..16 → 10002`：粉丝 8 条，其中 09、10 与本人互关，其余为 `FOLLOWED_BY`。
- 所有关系用户必须已经存在、状态为 `ACTIVE`，且用户名属于既有 `demo_user_*` DEMO 范围；不新增账号、不修改密码或 onboarding。

## 执行与保护

1. 先执行 `VR9_M1_USER_RELATION_SEED.sql`。
2. 连续执行 Seed 两次，行数应保持 20，不能覆盖非 VR9 关系。
3. 连续执行 `VR9_M1_USER_RELATION_VALIDATOR.sql` 两次；目标本人关注和粉丝均不少于 8，统计与有效入向关系一致，非 DEMO 泄漏为 0。
4. 未获 Plan 指示不得执行 Rollback；需要回滚时只执行 `VR9_M1_USER_RELATION_ROLLBACK.sql`。
5. Rollback 只删除 VR9 标记行，并按剩余有效关系重算用户 10002 的 `follower_count`，不恢复硬编码旧值。
