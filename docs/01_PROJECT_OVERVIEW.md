# 南看台项目总览

> 版本：v0.2-tifo-revised  
> 定位：说明南看台足球 APP 是什么、第一版目标是什么、核心业务闭环是什么，以及当前开发模式。本文不展开数据库字段、接口细节和部署命令。

## 1. 一句话说明

南看台是一个面向足球球迷的移动端 APP，核心能力是：

```text
卡片化足球内容流
+ 赛事数据工具
+ 球队/球员关注
+ 评论互动社区
+ 主队/关注驱动推荐
+ 数据驱动讨论
```

第一版不是完整复制懂球帝，也不是完整复制小红书，而是先做一个能跑通核心闭环的足球社区与数据平台。

## 2. 产品定位

```text
以足球内容和赛事数据为基础，围绕球队、球员、比赛事件组织讨论的球迷社区 APP。
```

核心差异点：

| 差异点 | 说明 |
|---|---|
| 主队体系 | 首次登录选择“我的主队”，主队会影响主页展示、头像标识、首页入口和推荐排序 |
| 关注体系 | 用户关注球队、球员、用户，后续推荐、排序、推送都与关注关系相关 |
| 卡片化首页 | 首页不是单一资讯列表，而是资讯、比赛、榜单、评分、讨论、热门评论等多卡片混排 |
| 数据入口 | 赛程、比分、积分榜、球员榜、球队榜、比赛详情是核心工具能力 |
| 数据驱动讨论 | 评论、评分、数据辩论场尽量围绕比赛事件、球员表现和统计数据展开 |
| 内容与数据绑定 | 内容可以关联球队、球员、比赛、赛事、热点事件，服务推荐和跳转 |

## 3. 第一版核心目标

第一版目标不是功能做全，而是先跑通：

```text
用户注册/登录
-> 首次登录选择主队、关注球队、关注球员
-> 浏览首页卡片流
-> 查看资讯/帖子/战报详情
-> 评论、回复、点赞、收藏
-> 查看球队/球员/比赛数据
-> 关注球队/球员/用户
-> 进入我的页面查看发布、点赞、收藏、评论、看台设置
-> 管理后台发布内容和维护基础足球数据
```

## 4. 用户角色

第一版只保留两类系统角色：

| 角色 | 说明 |
|---|---|
| `USER` | 普通用户，可以浏览、评论、点赞、收藏、关注、发布帖子、参与评分 |
| `ADMIN` | 管理员，可以管理内容、用户、球队、球员、比赛、基础数据、约球活动占位 |

第一版不设计复杂角色，例如运营、审核员、超级管理员、VIP 用户等。

## 5. 核心业务域

| 业务域 | 说明 |
|---|---|
| 用户域 | 注册、登录、用户资料、个人主页、首次登录偏好设置 |
| 内容域 | 资讯、帖子、战报、讨论卡片、媒体资源、内容关联标签 |
| 首页卡片域 | 资讯卡片、比赛卡片、排名卡片、评分卡片、讨论卡片、热门评论卡片 |
| 互动域 | 评论、二级回复、点赞、收藏、热评排序 |
| 关注域 | 关注用户、球队、球员、主队设置、粉丝/关注状态 |
| 足球数据域 | 联赛、球队、球员、比赛、赛程、积分榜、球员榜、球队榜、比赛统计 |
| 评分域 | 比赛球员评分、裁判评分、评分详情、平均分计算 |
| 消息域 | 系统通知、评论点赞提醒、关注提醒；私信作为后续待确认 |
| 约球域 | 约球列表、详情、报名、球场、聊天室；第一轮预留，不作为 P0 主线 |
| 管理后台域 | 后台登录、内容管理、基础数据管理、样例数据维护 |
| 推荐预留域 | 首页推荐、关注流、主队优先、热门赛事、去重和冷启动策略 |

## 6. 第一版不做什么

```text
完整私信 IM
完整约球聊天室
WebSocket 实时比分
第三方赛事数据 API 正式自动接入
复杂推荐算法和向量召回
复杂视频/GIF 集锦存储
Elasticsearch 全文搜索
Kafka 消息队列
ClickHouse 数据分析
Kubernetes 部署
多服务微服务拆分
广告系统
会员订阅和支付
```

这些能力可以在数据库、接口和模块中预留，但不作为第一版交付目标。

## 7. 开发模式

当前开发模式：

```text
Windows 本地开发
-> GitHub 托管代码
-> Windows 本地构建 Docker 镜像
-> docker save 导出镜像 tar 包
-> 上传到 Linux 服务器
-> docker load 导入镜像
-> docker compose up -d 运行
```

原因：

1. 当前主要在 Windows 上开发；
2. GitHub 保留提交记录；
3. Linux 服务器挂代理麻烦，不适合构建；
4. 服务器只负责运行，尽量不拉依赖、不拉业务镜像；
5. Docker 镜像部署更容易统一运行环境。

## 8. 第一版验收标准

| 验收项 | 标准 |
|---|---|
| 服务启动 | Spring Boot 服务可启动 |
| 接口文档 | Knife4j 可访问 |
| 登录鉴权 | 用户登录后获取 JWT，普通接口可鉴权 |
| 首次登录 | 能设置主队、关注球队、关注球员 |
| 首页 | 能返回多类型卡片流，至少支持资讯卡片和比赛卡片 |
| 内容详情 | 能查看资讯/帖子/战报详情 |
| 互动 | 评论、二级回复、点赞、收藏能跑通 |
| 足球数据 | 球队、球员、比赛、赛程、榜单基础查询可用 |
| 比赛详情 | 能展示总览、事件、统计、战报关联；评分可作为 P1 |
| 我的 | 能查看看台、发布、点赞、收藏、评论 |
| 管理后台 | 管理员能发布内容、录入球队/球员/比赛 |
| 测试 | 单元测试、接口测试、核心场景测试有基本覆盖 |
