# 南看台需求范围与版本边界

> 版本：v0.2-tifo-revised  
> 定位：定义南看台第一版、第二阶段和后续增强的功能范围，明确哪些必须做、哪些暂缓、哪些待确认。本文不写数据库字段和接口路径。
>
> 第一轮 Codex 开发只做到 P0 可演示闭环，不追求完整产品。

## 1. 第一版核心闭环

```text
注册/登录
-> 首次登录选择主队、关注球队、关注球员
-> 浏览首页卡片流
-> 查看资讯/帖子/战报详情
-> 评论、回复、点赞、收藏
-> 查看球队/球员/比赛数据
-> 关注球队/球员/用户
-> 进入我的页面查看个人内容和看台设置
-> 管理后台发布内容和维护基础数据
```

## 2. 优先级定义

| 优先级 | 含义 |
|---|---|
| P0 | 第一版必须完成，缺少则无法形成可演示闭环 |
| P1 | 第一版后期或第二阶段完成，用于体现产品特色 |
| P2 | 后续增强，前期只预留结构，不强制实现 |
| 暂缓 | 当前不要开发，避免拖慢后端骨架搭建 |

## 3. P0 必做功能

### 3.1 用户与首次登录

| 功能 | 说明 |
|---|---|
| 用户注册 | 用户名/手机号 + 密码注册 |
| 用户登录 | 登录成功返回 JWT |
| 当前用户信息 | 获取当前登录用户 |
| 首次登录偏好选择 | 首次启动后设置“我的主队、关注球队、关注球员” |
| 我的主队 | 主队用于用户主页、头像标识、首页入口和推荐权重 |
| 关注球队 | 后续首页、数据页、推荐、推送与关注球队关联 |
| 关注球员 | 后续首页、球员内容、推荐、推送与关注球员关联 |
| 用户资料 | 昵称、头像、简介、主队、关注统计 |
| 管理员账号 | 通过 `seed.sql` 初始化管理员 |

### 3.2 首页卡片流

首页不是单一资讯列表，而是多个卡片模块混合展示。

| 功能 | 说明 | 第一版建议 |
|---|---|---|
| 顶部搜索 | 首页顶部搜索框 | P0 占位 |
| 发布入口 | 用户发布帖子/文章入口 | P0 |
| 推荐 tab | 多类型卡片混排 | P0 做基础规则 |
| 资讯 tab | 只展示资讯文章卡片 | P0 |
| 关注 tab | 展示关注用户发布内容；关注较少时穿插高热内容 | P0 简化实现 |
| 我关注的球队入口 | 以球队图标 + 名称展示 | P0 |
| 热门赛事入口 | 欧冠、英超、西甲、中超等 | P1，可先 seed |

首页卡片类型：

| 卡片类型 | 说明 | 优先级 |
|---|---|---|
| 资讯新闻卡片 | 文章 + 帖子两种内容，共用卡片展示 | P0 |
| 比赛卡片 | A vs B，支持未开始、进行中、已结束 | P0/P1 |
| 热门评论卡片 | 展示高热评论及关联内容 | P1 |
| 热门讨论卡片 | 类似小红书“想法”，一个讨论标题开评论区 | P1 |
| 排名卡片 | 积分榜、射手榜、球队榜等 | P1 |
| 赛后球员评分卡片 | 比赛结束后推荐用户评分 | P1 |
| 转会消息卡片 | 关联官方转会新闻，后续转会资料库 | P2 |

资讯卡片展示规则：

```text
封面图：使用第一张图片，限制最高/最低比例，超出后裁切
标题：最多两行
热评：最多两行；没有达到热评标准则不展示
底部信息：头像、昵称、认证信息占位、发布时间、点赞数、评论数
帖子角标：帖子类型需要显示“帖子”标识
卡片上点赞/评论不直接操作，点击进入详情页后操作
```

### 3.3 内容与详情页

| 功能 | 说明 |
|---|---|
| 内容列表 | 首页、球队详情、球员详情、我的页面复用内容卡片 |
| 内容详情 | 支持资讯、帖子、战报、讨论详情 |
| 发布帖子 | 普通用户可发布帖子，可绑定球队/球员/比赛/热点事件 |
| 后台发布文章 | 管理员可发布资讯和战报 |
| 媒体展示 | 图片统一支持横向滑动 |
| 帖子形式 | 文字和图片集中显示，类似微博/小红书 |
| 文章形式 | 支持图文分段，例如图 + 文 + 图 + 文 |
| 关联标签 | 内容可关联球队、球员、比赛、赛事、热点事件 |

第一版建议：

```text
先实现帖子/文章两类内容的统一详情页；
图文分段能力可以做简单 JSON 结构或 extra_json 占位；
内容关联先允许后台手动选择，自动识别后期再做。
```

### 3.4 评论与互动

| 功能 | 说明 |
|---|---|
| 评论 | 用户对内容、比赛、球员评分详情发表评论 |
| 回复 | 支持二级回复 |
| 评论点赞 | 评论可点赞 |
| 内容点赞 | 内容可点赞 |
| 收藏 | 内容可收藏 |
| 热评排序 | 优先展示“优质 + 新鲜”评论 |

评论排序基础规则：

```text
热度分 = 点赞数 × 1 + 回复数 × 2
时间系数：
0~2 小时：1.5
2~12 小时：1.0
12~24 小时：0.7
超过 24 小时：0.3
最终排序分 = 热度分 × 时间系数
```

### 3.5 足球数据页

数据页是核心工具入口。

| 功能 | 说明 | 优先级 |
|---|---|---|
| 重要比赛 tab | 与关注无关，展示重点比赛，如欧冠淘汰赛、重要杯赛 | P0/P1 |
| 关注球队赛程 | 展示用户关注球队的赛程 | P0 |
| 赛事筛选 | 赛季、赛事筛选 | P1 |
| 赛程信息流 | 按时间顺序排列，默认定位到最近一场比赛 | P0 |
| 比赛卡片 | 点击进入比赛详情；已结束且有战报则显示战报入口 | P0 |
| 积分榜 | 联赛积分榜和杯赛积分榜展示不同 | P1 |
| 球员榜 | 射手榜、助攻榜、评分榜等 | P1 |
| 球队榜 | 球队相关榜单 | P1 |
| 杯赛淘汰赛树 | 类似 FotMob 淘汰赛交互，可保留总览树 | P2 |

### 3.6 球队详情

球队详情包括五个 tab：

```text
总览 / 帖子 / 球员 / 数据 / 赛程
```

基础规则：

| 功能 | 说明 | 优先级 |
|---|---|---|
| 球队头部 | Logo、名称、总身价、关注按钮 | P0 |
| 关注球队 | 用户可关注多支球队，第一版暂不设置数量上限 | P0 |
| 总览 | 集合重要信息，方便快速浏览 | P0/P1 |
| 帖子 | 展示关联该球队的新闻、帖子、卡片 | P0 |
| 球员 | 按前锋、中场、后卫、门将、教练分类 | P0/P1 |
| 数据 | 按赛季赛事筛选，支持总计/场均 | P1 |
| 赛程 | 按时间顺序展示球队赛程 | P0 |

球队总览建议板块：

```text
球队最近赛程（只显示一场）
球队排名（该球队参与赛事的排名）
最热资讯（展示 10 条）
队内榜单（射手、助攻、评分、解围、抢断）
球队信息（成立时间、地区、球场名称）
球队荣誉（冠军类型、次数、年份）
```

### 3.7 球员详情

球员详情包括：

```text
主页/总览、帖子、数据、比赛、 生涯
```

规则：

| 功能 | 说明 | 优先级 |
|---|---|---|
| 球员头部 | 头像、姓名、位置、年龄、俱乐部、国家队、关注按钮 | P0 |
| 所属俱乐部/国家队卡片 | 可点击跳转 | P1 |
| 已退役标识 | 退役球员显示“已退役”，减少比赛 tab | P1 |
| 帖子 | 展示关联该球员的内容 | P0 |
| 数据 | 赛季赛事筛选，总计/场均 | P1 |
| 比赛 | 需要包含俱乐部和国家队赛程 | P1 |
| 生涯 | 按球队、赛季两个维度展示出场、进球、助攻 | P1/P2 |

### 3.8 比赛详情

比赛详情包括五个 tab：

```text
评分 / 总览 / 阵容 / 排名 / 统计
```

| 功能 | 说明 | 优先级 |
|---|---|---|
| 比赛头部 | 比分、球队、比赛时间、赛事、状态 | P0 |
| 总览 | 战报、全场集锦、简要统计、关键事件 | P0/P1 |
| 事件时间线 | 进球、黄牌、红牌、换人、点球、VAR | P0 |
| 统计 | 控球率、射门、射正、绝佳机会、传球成功率、抢断、拦截、解围、扑救等 | P1 |
| 排名 | 展示该比赛对应赛事的排名信息 | P1 |
| 阵容 | 首发、替补、阵型、球员位置 | P1/P2 |
| 球员评分 | 用户对球员评分，可重复修改，后一次覆盖前一次 | P1 |
| 裁判评分 | “其他”tab 可展示主裁判评分入口 | P1/P2 |

评分规则：

```text
用户可以直接给球员评分；
每个用户对同一场比赛同一球员只有一条有效评分；
重新评分会覆盖上一次评分；
平均分需要重新计算；
评论和评分不强绑定，不评分也可以评论；
如果用户评论前已经评分，评论展示时可带评分标签。
```

### 3.9 我的页面

我的页面包括五个 tab：

```text
看台 / 发布 / 点赞 / 收藏 / 评论
```

| 功能 | 说明 | 优先级 |
|---|---|---|
| 看台 | 展示/修改主队、关注球队、关注球员 | P0 |
| 发布 | 用户发布的帖子/文章 | P0 |
| 点赞 | 用户点赞内容 | P0 |
| 收藏 | 用户收藏内容 | P0 |
| 评论 | 用户评论记录 | P0 |
| 后续工具卡片 | 转会中心、比赛竞猜等 | P2 |

### 3.10 粉丝与关注

关注状态包括：

| 状态 | 含义 |
|---|---|
| 回关 | 对方关注了我，我还未关注对方 |
| 已关注 | 我已关注对方，对方未关注我 |
| 互相关注 | 双方互相关注 |

交互规则：

```text
点击“回关”关注该用户；
点击“已关注”或“互相关注”可取关；
取关和关注前端弹窗确认；
后端返回当前关系状态。
```

| 功能 | 说明 |

| 首页多卡片混排 | 资讯、比赛、榜单、评分、讨论等统一卡片协议 |

| 球员详情生涯数据 | 生涯 tab、俱乐部/国家队数据 |

## 7. 待确认问题

| 问题 | 当前建议 |
|---|---|
| 私信功能是否做 | 第一版只做系统消息和互动消息，私信暂缓 |
| 资讯/帖子详情页形态 | 帖子和文章统一详情框架，但发布编辑形式区分 |
| 战报赛况来源 | 第一版后台录入，后期调研 API 或合规采集 |
| GIF/视频集锦 | 第一版只存外部链接，不存储视频文件 |
| 实时比分 | 第一版不做实时，先做静态比分和赛程 |
| 推荐算法 | 第一版规则排序，算法服务后期接入 |
| 球员评分是否进第一轮 | 建议放 P1，数据库和接口先预留 |
| 约球是否第一轮做 | 建议 P2 预留，不进入第一轮主线 |
| 杯赛淘汰赛树 | 展示复杂，建议后续完善 |
| 数据来源 | 后台录入 + seed 数据先跑通，后期再接 API/爬虫 |

## 8. 第一版演示脚本

```text
1. 管理员登录后台
2. 录入联赛、球队、球员、比赛
3. 发布一篇比赛战报和一篇帖子
4. 普通用户注册登录
5. 首次登录选择主队、关注球队、关注球员
6. 首页看到资讯卡片和比赛卡片
7. 用户进入战报详情
8. 用户评论、回复、点赞、收藏
9. 用户进入球队详情，查看总览、帖子、球员、赛程
10. 用户进入球员详情，查看帖子和基础数据
11. 用户进入比赛详情，查看战报、事件、统计
12. 用户进入我的页面，看到看台、发布、点赞、收藏、评论
```
